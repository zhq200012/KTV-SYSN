# KTV-SYSN · 现场跟唱助手

不接任何 KTV 点歌系统，只用手机麦克风听现场声音，自动识别当前歌曲、定位播放进度并持续同步，提供逐行/逐字歌词、和弦显示与进唱倒数提示。

## 当前阶段：M0 原型验证（Python 3）

M0 用 Python 验证「歌曲识别 + 进度定位 + 持续同步 + 歌词渲染」在真实 KTV 录音下的精度，**不做手机端**。M0 不达标不进 M1。
