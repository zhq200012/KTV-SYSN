### 3.6 变调变速鲁棒性（±1 半音、±5% 变速；决定是否切 Panako）【模拟】

- 变速 ±5%（2 段）：识别成功 2 段，Top-1 正确 2 段，定位误差中位数 43ms。

## 5. 遗留问题（区分真实 vs 模拟）

- 【真实（干净源）】识别准确率 / 初始定位误差 / 歌词同步为 1 首曲库、干净源自匹配结论，已消除「合成旋律」这一不确定项，但不覆盖人声跟唱 / 环境噪声 / 混响 / 版本差异。
- 【真实（干净源）已修复】重复副歌段误锁定 offset（原 1/7 段初始定位误差 123s、整曲行号回退）已通过「识别期窗口增长到 8s + offset 唯一性校验 + 失锁/暂停冻结进度修正」修复：全 7 段初始定位误差 ≤4ms、整曲歌词违规 0。
- 【待包房录音】鲁棒性指标（首次识别耗时、暂停 / 重唱 / 切歌 / 失锁恢复、人声跟唱与噪声下的识别率）仍为模拟结论，需真实包房录音后补齐。
- 【R1 待确认】「任意位置起播 <5s」是否含纯前奏：合成样本无静音前奏，真实曲目前奏指纹稀疏问题仅以干净源自匹配观察，未在带噪环境下验证。
- 【R3/R4 已触发】变调 ±1 半音、变速 ±5% 下 Shazam 式指纹失效，建议按 §3.6 启动 Panako 评估。
- 【对齐简化】M0 `align` 仅保留 LRC 行级时间戳，词级强制对齐（WhisperX）留 P1。
