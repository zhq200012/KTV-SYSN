# 测试集构成与标注规范（M0）

版本：v0.1 · 适用：M0 原型验证阶段

> 本规范定义评测测试集的构成、合成样本参数、真值标注格式与版权边界。数据管线按本规范造样本、标真值；评测脚本按本规范读真值、算指标。**音频与歌词不入库，真值标注文件不入库**（放本地 `data/eval/labels/`，`.gitignore` 排除），只有格式说明入库。

## 1. 目录组织

在 `data/`（DESIGN 4.5 数据根目录）下，测试集与曲库并列：

```
data/
  songs/<song_id>/...      # 曲库与时间轴（DESIGN 4.5，音频/歌词不入库）
  eval/
    labels/                # 真值标注（*.json，不入库）
      README.md            # 标注格式说明（入库，即本规范第 3 节）
    real/                  # 真实 KTV 录音 *.wav（不入库）
    synth/                 # 合成样本 *.wav（不入库）
    manifest.json          # 样本索引（入库：id / 相对路径 / 类别 / 参数 / 真值摘要）
```

- `.gitignore` 排除：`data/songs/**/*.wav`、`data/songs/**/*.mp3`、`data/songs/**/*.lrc`、`data/eval/real/`、`data/eval/synth/`、`data/eval/labels/*.json`。
- `data/eval/labels/README.md` 与 `manifest.json` 入库（纯文本，不含版权内容）。

## 2. 样本分类与最小规模

### 2.1 真实 KTV 录音（核心素材，需逐步积累）

覆盖场景（每类至少覆盖）：

| 场景 | 说明 |
|---|---|
| 人声跟唱 | 现场有人跟唱，人声与伴奏叠加 |
| 多人说话 / 碰杯噪声 | 非唱歌人声 + 环境冲击噪声 |
| 麦克风距离变化 | 手机离音箱不同距离 / 位置 |
| 前奏长度变体 | 同一首歌不同前奏长度的真实版本 |
| 升降调 | KTV 常见整体变调（真实变调，非合成） |

最小规模（建议）：

- 曲库内 **≥ 10 首**，每首 **≥ 3 段**（覆盖前奏 / 主歌 / 副歌不同起播位置）。
- 曲库外 **≥ 3 首**，每首 **≥ 2 段**（用于拒识测试）。
- 事件样本：暂停 / 重唱 / 切歌 **各 ≥ 5 段**。

> 真实录音不足时：先向人类要；在拿到之前用合成样本跑通链路，报告明确标注「模拟结论」，**不作为验收通过依据**。

### 2.2 合成样本（可控变量，跑通链路 + 变调变速鲁棒性）

生成方式：伴奏 + 人声 + 噪声混合（自制，无版权问题）。

参数网格（每首曲库内歌曲覆盖核心组合）：

| 维度 | 取值 | 说明 |
|---|---|---|
| 信噪比 SNR | −5 / 0 / 10 / 20 dB | 信号 = 伴奏+人声，噪声 = 环境/白噪/碰杯 |
| 人声叠加 | 人声增益 −6 / 0 / +6 dB | 模拟跟唱响度差异 |
| 跟唱偏移 | 0 / ±100 ms | 人声与伴奏不同步，模拟现场跟唱不齐 |
| 变调 | −1 / 0 / +1 半音 | 不变速（pitch shift） |
| 变速 | 0.95 / 1.0 / 1.05 | 不变调（time stretch） |
| 起播位置 | 前奏 0% / 10% / 25% / 50% / 75% / 90% | 覆盖整曲任意位置 |
| 前奏长度版本 | 原版 / 前奏 +5s / 前奏 −5s | 插入或裁剪前奏 |

最小规模（建议）：

- **≥ 5 首** × 每首 **≥ 30 变体**（覆盖 SNR × 变调 × 变速 × 起播位置核心组合）。
- 变调 / 变速维度各单独成组，便于 3.6 指标单独下结论。

## 3. 真值标注格式

### 3.1 标注文件

每样本一个 JSON，放 `data/eval/labels/<sample_id>.json`（不入库）：

```json
{
  "sample_id": "real_0001",
  "kind": "real",
  "audio_path": "eval/real/real_0001.wav",
  "song_id": "S001",
  "start_offset_sec": 61.20,
  "duration_sec": 25.00,
  "events": [
    { "t": 8.00,  "type": "pause",  "dur_sec": 2.0 },
    { "t": 15.00, "type": "replay" },
    { "t": 20.00, "type": "switch", "song_id": "S002", "start_offset_sec": 0.0 }
  ],
  "notes": "人声跟唱，轻微碰杯"
}
```

字段说明：

| 字段 | 含义 |
|---|---|
| `sample_id` | 样本唯一 ID |
| `kind` | `real` 或 `synth` |
| `audio_path` | 相对 `data/` 的音频路径 |
| `song_id` | 曲库内歌曲 ID；`null` 表示曲库外 |
| `start_offset_sec` | **起播点在参考音频中的秒数**（曲库外为 `null`） |
| `duration_sec` | 样本时长 |
| `events` | 暂停 / 重唱 / 切歌事件（可选） |
| `notes` | 自由备注 |

### 3.2 进度真值怎么标

- **回放样本**：真值进度 `= start_offset_sec + 自起播时刻起算的已回放时长`。
- **真实录音**：人工听音 / 看波形定位起播点在参考音频中的秒数 → `start_offset_sec`。
- **合成样本**：真值直接取生成参数（精确，无人工误差），`start_offset_sec` 与变调 / 变速参数一并记录。
- **允许标注误差：±50ms**（远小于 200ms 指标阈值，不影响结论）。

### 3.3 真值校验

`dataset-build` 或评测入口对标注做校验：`start_offset_sec + duration_sec ≤ 参考音频时长`；`events[].t` 单调不减且 `≤ duration_sec`；`song_id` 在 `manifest.json` 曲库索引中存在（曲库外除外）。

## 4. 版权与数据边界

- **音频与歌词不入库**：`.wav` / `.mp3` / `.lrc` / 含歌词文本的 `timeline.json` 一律不提交，`.gitignore` 排除，README 说明如何准备。
- **不提交无授权内容**：冷启动只用少量自制 / 授权数据验证技术，不下载、不提交无授权音频与歌词。
- **合成样本自制、无版权问题**，可自由生成与复现。
- 真值标注（`song_id` + 秒数偏移）是数字事实，但按本规范也**不入库**（放本地 `data/eval/labels/`），规避引用无授权曲目元数据带来的边界问题。
